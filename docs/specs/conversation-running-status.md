# 对话运行中状态

## 背景

当前对话工作状态使用旋转 loader，无法直观看到已经运行多久。官方 ZCode 使用像素矩阵动画、
“工作中”文案和高精度耗时；本仓库接入同一表现，同时保持已有推理过程常显。

## 所有权

- 推理行可见性继续由 `ConversationRowRenderContext.messageStreamShowReasoning` 决定，默认开启。
- 运行时长事实来自 turn/work segment 的 `workStatus.durationMs`；`ChatLoading` 只负责在两次
  上游更新之间做本地平滑推进。
- 不新增第二份 turn 状态，不把本地计时写回任务或协议。

## 产品规则

1. 运行中推理过程保持可见；用户设置关闭推理时仍按现有设置隐藏。
2. 运行中状态显示像素矩阵动画、“工作中”和高精度时长（十分之一秒）。
3. 时长从当前 work segment 已有 duration 起算；组件收到新的上游 duration 后重新校准。
4. 完成、等待用户输入、权限确认和 active work 阻断时，不显示运行中状态。
5. 减少动效偏好开启时关闭像素和文字动画，但仍显示静态状态与时长。

## 验收

- 运行中显示“工作中 1 分 28.7 秒”这类文案，并每 100ms 平滑更新。
- 已有耗时超过 0 时，组件首次显示从该值开始，不从 0 重新计时。
- 推理开启时，推理摘要和运行中状态可以同时存在。
- 完成或等待交互后运行中状态消失。
