# 课堂提示词预设的插入状态

## 背景

课堂提示词预设弹窗允许学生把平台下发的预设插入当前任务输入框。现有弹窗只在本次点击后
短暂标记选中项，无法区分“已经插入过”和“尚未插入”的预设，学生重复打开或连续插入时容易
重复操作。

## 所有权

- 平台预设列表由 `IPlatformService.classroom.getPresets()` 提供，组件不复制平台事实。
- “当前弹窗会话中哪些预设已经成功插入”是 UI 局部状态，由 `LingdongPresetsDialog` 独占。
- 输入框插入仍走 `useZCodeSessionStore.requestComposerTextInsert`，成功确认继续使用
  `useComposerTextInsertApplied`，不得在未确认时提前标记。

## 产品规则

1. 预设项必须有稳定的本地 key，由标题、正文和序号派生；刷新平台列表后仍能识别同一项。
2. 只有输入框确认应用成功后，才把该预设标记为“已插入”。
3. 已插入项使用明显的成功态背景、边框和“已插入”标识；未插入项保持普通卡片背景。
4. 当前正在插入的项显示进行中状态；插入失败不进入已插入集合，并保留可重试。
5. 弹窗关闭再打开时，同一组件生命周期内保留已插入集合；平台预设变化后，不再存在的项自然
   不再展示。
6. 不自动发送，不修改预设正文，不持久化到平台或本地存储。

## 验收

- 插入成功前卡片不显示“已插入”。
- 插入成功后卡片背景和边框与未插入项明显不同，并显示“已插入”。
- 插入失败时卡片不进入已插入集合，错误文案可重试。
- 关闭并重新打开弹窗后，已成功插入的同一预设仍保持已插入样式。
