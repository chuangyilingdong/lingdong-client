## 2026-09-20 第七轮 客户端启动更新与平台后台配置（已发布）

- 客户端启动时读取平台 `/downloads/manifest.json`；若版本更高，弹出“发现新版本”。

## 纪律

- 客户端仓只管客户端，平台服务端在另一个仓库。
- 发布前必须确认，不能直接跑 `publish-client.sh`。
- 插件 `apply` 抛错会导致 profile 白屏，必须 dev 先验。
- CDP 写 React 受控输入框用 `Input.insertText`，不要直接改 `.value`。
