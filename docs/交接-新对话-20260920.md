## 2026-09-20 第五轮反馈修复（未发布）

- 侧栏左下增加账号区：显示 `displayName + login`，提供“退出登录”。
- 退出登录先调用平台 `POST /api/auth/logout` 注销当前 token；即使平台请求失败，也会清掉本地登录态和课堂缓存并重启回登录页，不把学生卡在黑屏/主界面。
- 老师/机构端结束课堂后强制回登录页：主进程在已进入课堂期间每 5 秒轻量检查一次
  `client-context`；平台返回 `classroom: null`，或明确返回 `SESSION_SUPERSEDED` /
  `RUNTIME_KEY_INVALID` / `RUNTIME_KEY_EXPIRED` / `RUNTIME_NO_ACTIVE_CLASSROOM` 时，
  客户端清登录态并 `app.relaunch()`。普通网络抖动不会误退出。
- 侧栏左上 Logo 修复根因：原实现按约 4:1 的容器比例套 2.1:1 的图片，`objectFit: contain`
  把实际字标二次缩小了。现在保持原图 2.1:1，展开态按 34px 高渲染（约 71.4px 宽），
  并在侧栏品牌区水平居中；收起轨道仍按 24px 裁切显示。
- 平台侧无需为上述“结束课堂退出”改接口；当前实现基于已有 `client-context`。若要把退出延迟
  从最长约 5 秒进一步压到实时，才需要平台额外提供 SSE/WebSocket 事件或课堂结束推送。

## 纪律

- 客户端仓只管客户端，平台服务端在另一个仓库。
- 发布前必须确认，不能直接跑 `publish-client.sh`。
- 插件 `apply` 抛错会导致 profile 白屏，必须 dev 先验。
- CDP 写 React 受控输入框用 `Input.insertText`，不要直接改 `.value`。
