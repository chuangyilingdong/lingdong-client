## 平台端必须补的缓存用量透传

以下改动在平台仓 `E:\学习平台正常`，当前是只读，未直接修改。

文件：`E:\学习平台正常\apps\server\src\services\openaiCompatibleProvider.js`

现状：`tokenUsage(payload)` 只读取 `prompt_tokens` / `completion_tokens` / `total_tokens`，没有把缓存字段返回给 DSH。结果是客户端显示 `缓存命中 0%`，即使上游实际命中也无法观测。

建议的 `tokenUsage` 归一化逻辑：

```js
function tokenUsage(payload) {
  const usage = payload?.usage
  if (!usage || typeof usage !== 'object') return null

  const pick = (...keys) => {
    for (const key of keys) {
      const value = Number(usage[key])
      if (Number.isFinite(value) && value >= 0) return Math.round(value)
    }
    return null
  }

  const prompt = pick('prompt_tokens', 'input_tokens')
  const output = pick('completion_tokens', 'output_tokens')
  if (prompt === null && output === null) return null

  const cacheRead = pick(
    'prompt_cache_hit_tokens',
    'prompt_cache_hit',
    'cache_read_input_tokens',
  ) ?? (Number.isFinite(Number(usage?.prompt_tokens_details?.cached_tokens))
    ? Math.round(Number(usage.prompt_tokens_details.cached_tokens))
    : null)

  const cacheMiss = pick('prompt_cache_miss_tokens', 'prompt_cache_miss')
  const uncachedInput = cacheMiss ?? Math.max(0, (prompt || 0) - (cacheRead || 0))

  return {
    inputTokens: uncachedInput,
    outputTokens: output || 0,
    totalTokens: pick('total_tokens') ?? (prompt || 0) + (output || 0),
    ...(cacheRead > 0 ? { cacheReadTokens: cacheRead } : {}),
  }
}
```

同时确认平台 TEXT 请求透传/发送：

```json
{
  "stream": true,
  "stream_options": { "include_usage": true }
}
```

如果渠道不支持 `stream_options`，必须按渠道能力开关控制，不能无条件加。
