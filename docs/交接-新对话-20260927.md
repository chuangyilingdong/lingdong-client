## 4. 明确的产品决策（别再改反）
- **登录态只存内存**：关闭客户端（含崩溃/强杀）→ 下次必须重新登录；启动时清掉旧版本残留的 `lingdong-session*.json`。同一次运行内网络抖动/超时/5xx 不踢人（跳「连不上平台」等待页）；只有平台明确说凭据失效（401/403 / `SESSION_SUPERSEDED` 等）才回登录页。下课/课堂结束回登录页。
- **侧栏只显示当前课堂工作区**的会话；其它课堂/目录的会话不显示（交作品面板里另有"历史作品"折叠）。
- **发送次数客户端自己数**（localStorage，键 = 账号 + 课堂 id）；平台网关 429 仍是最终门禁。
- **交作品**：默认只看本节课、只默认勾「模型交付」（模型 `present` 的文件）；中间产物（backup/old/copy/草稿/draft/test/spec/tmp…）不进候选。
- **设计/PPT 插件**：预装 `deepseek-idesign@0.2.2` + `deepseek-ippt@0.1.2`，`deepseek-ivideo` 不装；显示层品牌全部换成灵动ai（小写标识符/路由/模板 id 不动）。
- **插件市场/社区插件/插件管理器**在学生端关闭。
- **HTML 预览**：放行本页相对资源与 fetch（同路由 + CORS），并注入内存 Storage 兜底。
